# 🌿 HerbBase — คลังข้อมูลอาหารเสริมและสมุนไพร

แอปฐานข้อมูล (โมโนกราฟ) ผลิตภัณฑ์เสริมอาหารและสมุนไพรที่ **ไม่ใช่ยา**
โดยจัดโครงหัวข้อ (outline) ตามรูปแบบของ **UpToDate / Lexidrug** เพื่อให้ข้อมูลแต่ละรายการ
มีมาตรฐานและครบถ้วนเหมือนโมโนกราฟยา

> ⚠️ ข้อมูลในระบบจัดทำเพื่อการศึกษาและอ้างอิงภายในเท่านั้น ไม่ใช้แทนคำแนะนำของแพทย์/เภสัชกร

## คุณสมบัติ

- **ค้นหา** ชื่อไทย / อังกฤษ / ชื่อวิทยาศาสตร์ / ชื่อพ้อง พร้อมกล่องแนะนำอัตโนมัติ
- **เรียกดูตามหมวดหมู่** (สมุนไพร, วิตามิน, แร่ธาตุ, กรดไขมัน, โพรไบโอติก ฯลฯ)
- **หน้าโมโนกราฟ** มีสารบัญ (outline) แบบเลื่อนตาม, ย่อ/ขยายหัวข้อ, แบนเนอร์แจ้งเตือน, ลิงก์อ้างอิง และปุ่มพิมพ์
- **สลับแสดง/ซ่อนหัวข้อที่ยังไม่มีข้อมูล** — เห็นโครงครบทุกหัวข้อแม้ยังไม่ได้กรอก
- **เครื่องมือ “เพิ่มข้อมูล”** (builder.html) สร้างฟอร์มจากโครงหัวข้อโดยอัตโนมัติ แล้วส่งออกเป็นไฟล์ `.js` พร้อมใช้
- ทำงานแบบ **static ล้วน** ไม่ต้องมี backend/ฐานข้อมูล — เปิดไฟล์ตรง ๆ หรือ deploy บน GitHub Pages ได้
- รองรับ **โหมดสว่าง/มืด** อัตโนมัติ และภาษาไทยเต็มรูปแบบ

## โครงหัวข้อโมโนกราฟ (Outline)

จัดตามรูปแบบ UpToDate — ดูโครงเต็มได้ที่ [`js/schema.js`](js/schema.js):

`ALERTS` (US Boxed Warning) · `Brand Names` (US/Canada) · `Pharmacologic Category` ·
`Dosing` (Adult/Pediatric + Kidney/Liver Impairment, Older Adult) · `Adverse Reactions` ·
`Contraindications/Warnings` · `Preparations` (Dosage Forms, Pricing) · `Administration` ·
`Storage/Stability` · `Uses` (Labeled / Off-Label) · `Medication Safety Issues` ·
`Interactions` (Metabolism/Transport, Drug Interactions) ·
`Reproduction, Pregnancy, Lactation` · `Monitoring` ·
`Pharmacology` (Mechanism of Action, Pharmacokinetics) ·
`Medication Guide` · `Patient Counseling Points` · `Brand Names: International` · `REFERENCES`

## โครงสร้างไฟล์

```
Health-Project/
├── index.html              # หน้าหลัก (หน้าแรก / รายการ / โมโนกราฟ)
├── builder.html            # เครื่องมือเพิ่มข้อมูล (สร้างไฟล์โมโนกราฟใหม่)
├── css/style.css           # สไตล์ทั้งหมด (รองรับ dark mode + โหมดพิมพ์)
├── js/
│   ├── schema.js           # ★ นิยามโครงหัวข้อ (outline), หมวดหมู่, สถานะ
│   ├── registry.js         # ทะเบียนกลางเก็บโมโนกราฟ
│   ├── app.js              # ตรรกะแอปหลัก (routing, ค้นหา, render)
│   └── builder.js          # ตรรกะหน้าเพิ่มข้อมูล
└── data/
    ├── manifest.js         # ★ รายชื่อไฟล์ข้อมูลที่จะโหลด
    └── monographs/
        ├── _template.js    # แม่แบบสำหรับสร้างรายการใหม่
        ├── turmeric.js     # ตัวอย่าง: ขมิ้นชัน (ข้อมูลค่อนข้างครบ)
        ├── fish-oil.js     # ตัวอย่าง: น้ำมันปลา
        └── andrographis.js # ตัวอย่าง: ฟ้าทะลายโจร (ข้อมูลบางส่วน)
```

## การใช้งาน

เปิด `index.html` ด้วยเบราว์เซอร์ได้เลย หรือรันเว็บเซิร์ฟเวอร์ในเครื่อง:

```bash
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000
```

## วิธีเพิ่มข้อมูลรายการใหม่

**วิธีที่ 1 — ใช้เครื่องมือในเว็บ (แนะนำ)**
1. เปิด `builder.html`
2. กรอกข้อมูลตามหัวข้อ (เว้นว่างหัวข้อที่ยังไม่มีข้อมูลได้)
3. กด “สร้างไฟล์ข้อมูล” → “ดาวน์โหลด .js”
4. วางไฟล์ใน `data/monographs/` แล้วเพิ่มพาธใน `data/manifest.js`

**วิธีที่ 2 — แก้ไฟล์เอง**
1. คัดลอก `data/monographs/_template.js` เป็นไฟล์ใหม่
2. แก้ `id` (ห้ามซ้ำ) และเนื้อหาในแต่ละหัวข้อ (`sections`)
3. เพิ่มพาธไฟล์ใน `data/manifest.js`

### รูปแบบเนื้อหาในแต่ละหัวข้อ

- ข้อความล้วน: บรรทัดว่าง = ย่อหน้าใหม่, `- ` = รายการจุด, `1. ` = รายการเลข, `## ` = หัวข้อย่อย, `**หนา**` `*เอียง*`, อ้างอิง `[1]`
- หรือใช้อาร์เรย์ของบล็อกเพื่อทำ **ตาราง/กล่องหมายเหตุ**:
  ```js
  adultDosing: [
    'ข้อความนำ',
    { note: 'ข้อความในกล่องเน้น' },
    { table: { headers: ['คอลัมน์ 1', 'คอลัมน์ 2'], rows: [['a', 'b']] } },
  ]
  ```
- หัวข้อ `references` ใช้เป็นอาร์เรย์ของข้อความ อ้างอิงในเนื้อหาด้วย `[1]`, `[2]`
